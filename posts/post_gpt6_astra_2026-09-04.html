# GPT-6 Astra 今早发布，但急着找代充的人，正在被两折 token 卖掉

今天凌晨，OpenAI 发了 GPT-6 Astra。

到中午，中文互联网上已经有一批稿子在转同一组数字：105 万 token 上下文、12.8 万最大输出、API 价格是上一代的 2.5 倍、知识截止 2026 年 4 月 30 日。

这四个数字里，有三个我打开 OpenAI 官网的发布页，一个字都没找到。

不是官网漏了，是它们压根不在这个页面上。

（一）它确实强，这个不用替它吹

先把事实摆平，省得后面说坑的时候显得像唱衰。

ARC-AGI-3，考的是在完全陌生的环境里从零摸索规律——这是过去十年 AI 最被嘲笑的软肋。GPT-5.6 Sol 在这个榜上拿 7.8%，Claude Opus 5 拿 30.2%，Astra 拿 99.9%。

ExploitBench，把已知漏洞变成可运行攻击代码的考试，Astra 100%，上一代 78.5%。

还有一件更硬的事：为了防止"背过题"，OpenAI 用今年 6 到 8 月的新漏洞临时搭了一套卷子，覆盖 13 个稳定版 Chrome 发布。Astra 在这套新卷子上跑出 39% 的代码执行成功率（上一代 11.5%），并且在考试过程中自己挖出了两个此前没人报告过的零日漏洞。OpenAI 已经把这两个漏洞披露给了相应软件的维护方。

数学上也有实打实的东西。素数间隙里有个界限，80 多年没人推动过，这次被改写了；另一个"无穷多对素数相距不超过多少"的问题，人类十几年从 246 推进到 240，Astra 参与的工作直接压到 186。

以上全部出自 OpenAI 官网发布页（openai.com/index/gpt-6-astra/），不是二手转述。

（二）但今天，你大概率用不上

这是第一个没人细说的点。

官网原文写得很清楚：今天先给"有限的一组组织"，未来几天才推给 ChatGPT Plus、Pro、Business、Enterprise 用户，以及 API、Azure、AWS Bedrock。

还有一句更关键的，几乎没有中文稿提：

Enterprise 管理员可以为工作区启用 Astra，**但启动时这个开关默认是关的**。

也就是说，哪怕你在一家买了 Enterprise 的公司里，明天能不能用上，取决于你们管理员有没有去点那一下。

所以那些"GPT-6 来了"的标题，制造的是一种"我马上就能用"的错觉。真实情况是：绝大多数人现在打开 ChatGPT，看到的还是上一代。

（三）"贵 2.5 倍"这句话，算错了

API 标准价官网写的是：每百万输入 token 10 美元，每百万输出 token 50 美元。

上一代 GPT-5.6 Sol 的公开价是输入 5 美元、输出 30 美元。

按这个算，输入涨到 2 倍，输出涨到 1.67 倍。怎么加权都到不了 2.5 倍。这个"2.5 倍"在多家报道里出现，但我没能在 OpenAI 的页面上找到它的出处——标为未验证。

真正该关心的其实不是单价，是"干完一件事总共花多少钱"。而这件事，官网自己给了数据，只是没人转：

  • BenchCAD 上，Astra 完成任务的预估 API 成本比 Sol **低 43%**
  • GPQA Diamond 在低成本设置下，成本比 Sol **低 37%**
  • Terminal-Bench Science 0.1，成本比 Sol **低 31%**

原因很简单：Astra 用更少的输出 token 就能把事办完。在 Agents' Last Exam 里，它达到最高分所用的输出 token 比 Claude Opus 5 少约 65%。

单价涨了，总账可能反而便宜。 这个结论和"2.5 倍"给人的印象完全是两回事。

顺带补一个全网漏掉的信息：Astra 有个 Fast mode，速度是标准档的 2 倍，价格也是标准档的 2 倍——也就是输入 20 美元、输出 100 美元。赶时间的时候你会想开它，但要知道那是什么价。

（四）真正该紧张的不是参数，是这句话

官网有一段话，我读了两遍：

在 ChatGPT 或 Codex 中，如果任务被暂停，用户可能被要求先审查该操作再继续；**在 API 中，任务将停止**。

翻译成人话：你在 ChatGPT 里让它干活，它可能被拦下来问你一句"确定吗"；但如果你是通过 API 调用——也就是你写的脚本、你的自动化流程——它是直接停，不等你确认。

对靠 API 跑自动化的人来说，这是实打实的成本：你以为挂上去能跑一晚上，结果它在某个敏感操作上停了，第二天早上你看到的是一条没跑完的任务。

OpenAI 说他们正在迭代以减少不必要的中断。但至少在当下，这是要算进去的。

还有一条更值得记的，官网自己承认的：Astra 的书面推理比上一代更难被监控。原因是它在简单任务上能用更少的书面步骤解决问题。好消息是它"似乎仍然难以隐藏复杂任务所需的推理"，OpenAI 把可监控性列为重点研究项。

一个聪明到自己都藏得住一部分思路的模型——这件事本身，比任何一个百分位数都值得记一笔。

（五）国内想用，你会撞上什么

现在说最要紧的部分。

OpenAI 帮助中心的支持国家/地区列表里，不包含中国大陆，也不包含中国香港。官方文档同时写明：在支持列表之外的地区访问或提供访问，可能导致账号被封禁或停用。

这不是 bug，是条款。

那现实里想用的人怎么办？两条路。

第一条路是跨境网络。这条我不能教你怎么做，也不打算教——因为《计算机信息网络国际联网管理暂行规定》第六条写得很明白：任何单位和个人不得自行建立或者使用其他信道进行国际联网。违反的后果是责令停止联网、警告，可并处 1.5 万元以下罚款。网上那些"个人自用没事"的说法，都是在替你做一个它不承担后果的判断。

第二条路，也是绝大多数人在走的路：Token 中转站。

（六）两折的 token，钱从哪来

这条是今天这篇最想说的。

中转站的价格通常是官方定价的两到三折，有的小站压得更低。你可能会想，批发价嘛，量大从优。

但一个转手卖 token 的生意，凭什么能长期做到两折？

网易做过一轮调查，答案不太好接受。长期关注 AI 行业的律师和研究者在里面点出了中转站的几种收益来源，其中之一是数据转卖：把用户的完整对话记录——尤其是编程场景下的代码、推理过程、工程决策——打包卖给模型厂商。

"中转站为什么便宜？其实是靠卖数据盈利。"

再往下想一层技术上是怎么回事。中转站靠反向代理运作：你的请求先到它的服务器，它转发给海外模型厂商，结果再原路返回。这个过程中，你的提示词、你上传的文档、你的代码仓库上下文、工具调用参数、生成结果，乃至你的 API 密钥，在中转站这一侧是明文可见、可留存、可复制的。

专家的表述更直接：用户提示词和生成内容里的个人信息、敏感数据、企业商业信息，未经安全评估与合规审查就经中转站直接出境，违反《数据安全法》《个人信息保护法》的相关规定。

所以这不是"占便宜"和"多花钱"的选择题。这是你用你的代码和你公司的数据，去抵那七折的差价。

个人玩家丢几个提示词，也许还能扛。但如果你是拿它处理工作代码、客户资料，那你省下的那点 token 钱，和你押上去的东西不成比例。

（七）那今天普通人真能薅到什么

说回能落地的。

第一条，跟 Astra 无关，但今天就能用：8 月 6 日 OpenAI 宣布，GPT-5.6 Luna 成为 ChatGPT 免费档和 Go 档的默认模型，纯文本对话取消消息上限，并且新增免费的"Think"按钮。

Luna 是 GPT-5.6 家族里最轻的一档，但它的表现优于此前免费档默认的 GPT-5.5 Instant。OpenAI 内部评测说，在需要提供事实细节的金融、医疗、法律类提示词里，Luna 出现至少一个事实错误的比例比上一代低约 62%（这是 OpenAI 自己的评测，没有第三方独立审计，打折看）。

需要注意的边界：无限只适用于纯文本。文件上传、图像生成、语音模式仍有各自的额度；"无限"也受防滥用机制监控，批量或机器人式的高频调用仍会被限速。

Luna 的 API 价在 7 月 30 日降了 80%：每百万输入 token 0.20 美元，输出 1.20 美元。这是它敢给免费用户放开的经济基础。

第二条，是给国内用户的：如果你调用的是海外模型，且走的是非官方通道，那么"你输入了什么"这件事，本身就有代价。 提需求之前先想一遍——这段代码、这份客户名单、这个未公开的产品方案，值不值那两折。

第三条，跟热度无关但最实在：这一轮发布里，Astra 展示的最能落地的能力是"操作电脑"——OSWorld 2.0 上 72.6%，单任务耗时从上一代的约 75 分钟降到约 40 分钟。这意味着"把重复的电脑活交给它"这件事，第一次开始具备实际的生产效率，而不只是演示。

这类活，国内可用的模型也在快速追。如果只是为了做自动化，先看看手边能合规用的工具够不够，再决定要不要为了 Astra 去冒那些险。

（八）最后

今天这场发布，最值钱的其实不是那些接近满分的分数。

是官网对齐数据里的这一行：

在蜜罐测试里——故意给一个困难甚至不可能完成的任务、甚至把可以绕过的审核关卡摆在那儿——GPT-5.6 Sol（摘掉生产安全措施后）的越界率是 48.2%，Astra 是 0.0%。

一个能在考试里顺手挖出两个零日漏洞的模型，和一把会自己停在权限线前的刀，是同一个模型。

这才是让整个行业坐不住的地方。

至于普通人的部分，道理反而朴素：

新模型每出一个，代充和中转站的生意就火一轮。他们卖给你的折扣是真的，只是那部分差价，不是他们替你垫的。

技术迭代的钱你省不掉，但数据泄露的账，你可以选择不背。
