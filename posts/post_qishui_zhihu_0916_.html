# 普通人做汽水音乐推广，到底能赚多少？实测单价 + 避坑（2026）

太长不看版：汽水音乐（字节系）对外放推广，普通人能赚的就是两条——拉新（推人注册）和 CPE（发内容按互动结算）。纯自己听歌不值钱。下面是我扒下来的真实单价和坑，不吹不藏。

一、钱从哪来（我交叉了三个来源）

路径 单价 可靠度
拉新 9.5~15 元/人 三个来源一致，可信
CPE 按互动 0.3 元/互动，单条封顶 1500 项目存在（星子助推多源印证），单价单一来源

结论：CPE 天花板最高（月 900~3000），但要持续产内容；拉新最快见钱，适合不想拍视频的。

二、两条路怎么跑

拉新（不发内容也能做）

  1. 拉新挂件要报名审核才拿得到：抖音搜「Star 达人计划」→ 找到【STAR 计划海量任务招募中】→ 立即参与 → 任务选「汽水音乐 APP 推广任务」→ 等审核；或汽水音乐 App 内「我的 → 达人招募」提交报名；或任推邦小程序报备（9.5 元/人）。⚠️ 网上说的"0 粉无门槛"指的是**自己建汽水歌单挂件**，那个**不带佣金**——别把"能挂上去"当成"能拿到钱"。
  2. 把专属链接发朋友圈/群，话术："免费听千万正版歌，扫码领会员"
  3. 真人注册激活 → 9.5~15 元/人

    4. CPE（发内容）

    1. 微信「星子助推」小程序，填高佣码 `8x25k`，领汽水音乐物料包
    2. 发视频号/图文带挂载
    3. 0.3 元/互动，单条封顶 1500
      4. 星子助推我验过，真实存在（北京星子文化，确有汽水 CPE 授权）。但网上"月入2万"是软文夸张，按实测天花板（封顶1500、月900~3000）为准。

      三、坑（先标）

      • **刷量封号**：必须真实注册/互动，机刷必封且不算钱
      • **报备打回**：字段填错（昵称/链接不对）会被打回，耽误几天
      • **对账有周期**：不是实时到账，别当天没到就以为没生效
      • **CPE 挂载判定**：必须带汽水挂载且互动真实，硬广搬运不计数

      四、天花板（开工前算过）

      CPE：30 条×100 互动×0.3 ≈ 900，爆一条 5000 互动 = 1500 封顶。

      拉新：月推 50 人×12 ≈ 600。

      纯听歌：月 30~80，别走。
