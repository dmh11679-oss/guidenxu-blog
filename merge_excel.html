merge_excel.py

把一个文件夹里的 Excel / CSV 合成一张，自动标出每行来自哪个文件

命令行小工具 · 数据不出本机 · MIT 开源

它解决的是哪一种活

每月十几家分店、分公司、分月报表，结构一模一样，要粘成一张给老板看。手工复制粘贴的下场你大概经历过：粘到第七个开始串行，金额列看着是数字，求和出来是 0。

这个脚本只干一件事：把一个目录里结构相同的表合成一张，并自动加一列「来源文件」，标明每一行是从哪个文件来的。

先说门槛，别白看

它是命令行工具，不是网页、不是在线转换器。跑它你需要：电脑上装了 Python，再装一个依赖 openpyxl。

本机实跑环境是 Python 3.12.10 + openpyxl 3.1.5（2026-09-30 复现，输出见下文）。作者 README 写的是「Python 3.8+ 都能跑」，这个我没逐个版本去验，只在 3.12 上真跑过。

如果你不想碰命令行，看到下面「真跑一遍的输出」就够了 —— 至少你知道合并完应该长什么样、哪些地方会坑你。

安装

pip install openpyxl

就这一个依赖。

用法

python merge_excel.py <目录> [-o 输出.xlsx] [--sheet 工作表名] [--keep-header] [--raw]
参数作用
-o输出文件名，默认写到 <目录>/合并结果.xlsx
--sheet指定读哪个工作表，默认读第一个
--keep-header每个文件都保留表头（默认只留第一份文件的表头）
--rawCSV 不做数值识别，全部按文本写入

真跑一遍的输出（本机复现，不是示意）

输入 3 个文件（2 个 xlsx + 1 个 csv），其中 CSV 里放了千分位金额 "1,500" 和前导零编码 007：

$ python merge_excel.py ./报表 -o 合并结果.xlsx
输出: ./报表/合并结果.xlsx
合并 2 个文件，共 4 行数据
   杭州店.xlsx                         1 行
   边界测试.csv                         3 行

合成之后，我把结果文件逐格读回来打印了真实值和真实类型（括号里是写进 Excel 的类型）：

订单号日期销量金额备注来源文件
2001 (int)2026-08-05 (文本)9 (int)900 (int)xlsx来源杭州店.xlsx
1001 (int)2026-08-01 (日期)12 (int)1200 (int)正常边界测试.csv

注意那两处："1,500" 变成了数字 1500（能求和），007 保持 文本 007（没被改成 7）。

它处理掉的三个真实坑

CSV 读进来一律是字符串。直接写进 Excel，数字列会变成文本 —— 看着像数字，求和却是 0。这个工具做了三件事：

  1. 数字还原：1200 写成数字 1200，不是文本 "1200"。
  2. 千分位还原："1,500" 还原成 1500。含逗号但不是千分位的字符串（比如备注里的逗号）原样保留，不乱拆。
  3. 不擅自改你的数据：007 这种前导零编码（工号、门店号、部门码）保留为文本，不会被改成 7。日期 2026-08-01 写成真日期，可以直接做透视表。

拿不准的一律当文本，不猜。想全部按文本写，加 --raw。

已知限制（先看这个，别踩坑）

  • 不支持旧版 .xls（Excel 97-2003）。只支持 .xlsx 和 .csv。我实测放了一个 .xls 进去，它会打印一行「跳过 老报表.xls（读取失败: openpyxl does not support the old .xls file format…）」然后继续跑，不会中断，也不会静默丢数据。
  • 假设各文件列结构一致（列的顺序和含义相同）。列名不同、顺序不同的表（比如不同银行的账单），合并前得自己先把列名对齐，这个工具不做自动对齐。
  • 只读每个文件的第一个工作表（或用 --sheet 指定一个）。多工作表合并暂不支持。
  • 公式单元格读的是计算结果（代码里 data_only=True）。文件从没被 Excel 打开过、没有缓存结果时，会读到空。

还有一个我自己跑出来的细节：输出默认就写在输入目录里，脚本只排除「与输出同名的那个文件」。如果你换了个 -o 名字再跑一遍，上一轮的合并结果会被当成新输入再合一次 —— 行数翻倍。要么固定用默认名，要么每次输出到别的目录。

为什么做成命令行，不做成网页

因为这活的典型场景是「文件夹里躺着 30 个门店报表，每月来一次」。命令行一条语句跑完，不用每次开网页、不用把报表上传到任何服务器 —— 数据不出本机。

反过来说，这也是它的门槛：你要能敲命令行。我没有包装成 exe 或界面，包装了就是另一个价格的事了。
